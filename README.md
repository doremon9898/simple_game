# Zombie Shooter

เกมยิงซอมบี้มุมมองจากด้านบน (Top-down Shooter) เขียนด้วย Python + tkinter
เล็งด้วยเมาส์ เดินด้วยคีย์บอร์ด เอาตัวรอดจากซอมบี้ให้ได้นานที่สุด

## วิธีรัน

ต้องมี Python 3 (มี tkinter มาให้ในตัวแล้ว ไม่ต้องติดตั้งอะไรเพิ่ม)

```bash
python game.py
```

## การควบคุม

### หน้าเมนู

| ปุ่ม | การทำงาน |
|---|---|
| `1` - `5` หรือคลิกการ์ด | เลือกอาวุธ |
| `←` `→` หรือคลิกฉาก | เลือกฉาก |
| `Enter` หรือคลิกปุ่ม "เริ่มเกม" | เริ่มเล่น |

### ในเกม

| ปุ่ม | การทำงาน |
|---|---|
| `W` `A` `S` `D` / ลูกศร | เดิน |
| เมาส์ | เล็ง |
| คลิกซ้าย | ยิง (ไรเฟิลกดค้างยิงรัวได้) |
| `Space` | พุ่งหลบ (Dash) ไม่โดนดาเมจระหว่างพุ่ง คูลดาวน์ 1.5 วินาที |
| `R` | รีโหลด |
| `P` | หยุดเกมชั่วคราว |

### หน้าจบเกม

| ปุ่ม | การทำงาน |
|---|---|
| `Enter` | เล่นใหม่ด้วยอาวุธและฉากเดิม |
| `M` | กลับหน้าเมนู |

> ปุ่มตัวอักษรใช้ได้แม้คีย์บอร์ดเป็นภาษาไทย (บน Windows)

## อาวุธ

| # | อาวุธ | กระสุน/แม็ก | จุดเด่น |
|---|---|---|---|
| 1 | ปืนพก | 12 | แม่นยำ รีโหลดไว |
| 2 | ไรเฟิลจู่โจม | 30 | กดค้างยิงรัว |
| 3 | ลูกซอง | 6 | กระจาย 7 นัด แรงในระยะใกล้ |
| 4 | สไนเปอร์ | 5 | ดาเมจสูง ทะลุได้ 4 ตัว |
| 5 | เครื่องยิงระเบิด | 4 | ระเบิดวงกว้าง กวาดฝูงซอมบี้ |

## ฉาก

| ฉาก | ลักษณะ |
|---|---|
| สุสานร้าง | ป้ายหลุมศพขวางทาง เหมาะกับมือใหม่ |
| เมืองร้าง | ยิงถังน้ำมันให้ระเบิดได้ (ระเบิดต่อกันเป็นทอด) แต่ถ้ายืนใกล้จะโดนด้วย |
| ป่ามืด | ต้นไม้และหินหนาแน่น ซอมบี้เร็วขึ้น 15% |

สิ่งกีดขวางบังทั้งการเดินและกระสุน ตำแหน่งสุ่มใหม่ทุกเกม

## ซอมบี้

| ชนิด | ลักษณะ | เริ่มเจอ |
|---|---|---|
| Walker | ธรรมดา | Wave 1 |
| Runner | เร็ว เลือดน้อย | Wave 2 |
| Brute | ตัวใหญ่ ถึก ตีแรง | Wave 3 |
| ราชาซอมบี้ (บอส) | เลือดเยอะมาก มีหลอดเลือดด้านล่างจอ | ทุก ๆ 5 Wave |

## กติกาและเคล็ดลับ

- ซอมบี้มาเป็น Wave แต่ละ Wave มีจำนวนมากขึ้นและเร็วขึ้น
- ผ่าน Wave ได้โบนัสคะแนน (Wave × 25)
- ซอมบี้มีโอกาสดรอป **กล่องปฐมพยาบาล** (+25 HP) กล่องจะกระพริบก่อนหายไป บอสดรอป 3 กล่อง
- ใช้ Dash พุ่งทะลุวงล้อมตอนโดนรุม
- สถิติคะแนนสูงสุดถูกบันทึกไว้ในไฟล์ `highscore.txt`
